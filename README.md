# TobyMap

An accessible map of the world for blind and partially sighted people.

You move around the map step by step. You hear where you are, what you are crossing and what is near, using a screen reader, Braille and spatial sound. Sighted and partially sighted users see the same map drawn on a globe.

TobyMap will come as a Windows desktop application and a web application, both built from one shared Python core.

## Status

TobyMap is in Phase 0: foundations and technical spikes. There is nothing to install yet. The first release will come at the end of Phase 1.
