Spike S3: hosting and browser storage

This page tests two things for the web version of TobyMap. First, whether a web page can make range requests, reading a few bytes from anywhere in a file without downloading all of it, to each place a pack could be stored. Second, how much this browser lets a web site keep in its private file storage.

Results go into the Results box. When a test finishes, the page says so.
